# Map App - React Native приложение с картой

Мобильное приложение для работы с картами и управления изображениями, привязанными к географическим меткам.

## Функциональность

- Отображение интерактивной карты
- Добавление меток долгим нажатием
- Прикрепление изображений к меткам
- Удаление изображений
- Навигация между экранами

## Технологии

- React Native
- Expo
- TypeScript
- React Native Maps
- Expo Image Picker
- Expo Router
